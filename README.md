# Tradutor de Commits

Atividade prática utilizando o padrão Conventional Commits.

## Objetivo
Padronizar mensagens de commit para melhorar a organização, clareza e manutenção do projeto.

## Commits realizados

- fix(login): corrige erro no botão de login no Safari devido a incompatibilidade de função JS
- feat(profile): adiciona tela de histórico de pedidos do usuário
- feat(api): renomeia campo userName para fullName
